# 应用频段射频测试报告

> **目的**：验证应用频段 **2474 / 2476 / 2478 MHz**（`RF_Uart/APP/include/rf.h` 里的
> `CH_HOP_TBL = {74, 76, 78}`，按 `f = 2400 + ch`）的**发射性能是否正常**，
> 重点看频偏与三个频点的功率一致性（尤其 2478 MHz 靠近 2.4G 上限 2483.5 MHz，是否有滚降）。

---

## 三、测试结果

### 3.1 载波频率

| 应用信道 | 标称频点 | 实测频率 | 偏差 | 偏差 (ppm) |
|---|---|---|---|---|
| 74 | 2474 MHz | **2473.980 MHz** | −20 kHz | **−8.1** |
| 76 | 2476 MHz | **2475.988 MHz** | −12 kHz | **−4.9** |
| 78 | 2478 MHz | **2477.986 MHz** | −14 kHz | **−5.7** |

**三点全部满足 ±10 ppm 目标**，最大偏差 20 kHz（仅占 2 MHz 信道宽度的 1%）。

> **测量说明（重要，影响 ppm 的解读）**
>
> 1. 标称频点按 `f = 2402 + 2×ch` 计算。该接口的信道编号已由 ch36 实测确认为**线性**
>    （ch36 → 2474 MHz），与 `rf.h` 的 `{74,76,78}` 换算一致（2474→36 / 2476→37 / 2478→38）。
> 2. **频谱仪读数受设置与显示分辨率影响**：ch36 在同一次测试中，Span 100 MHz 宽扫读作
>    2473.976 MHz（−24 kHz），缩到 Span 1 MHz 后读作 2473.980 MHz（−20 kHz）。
>    本次 ch36 的读数分辨率为 10 kHz（±5 kHz ≈ ±2 ppm），ch37 / ch38 为 1 kHz。
> 3. 三点的 ppm 偏差并不一致（−8.1 / −4.9 / −5.7）。若偏差纯由**仪器时基**造成，
>    三点应表现为**同一个 ppm 偏移**，因此这里仍混有测量不确定度（读数分辨率、
>    冷热机状态、仪器时基精度）。
> 4. 因此：**DUT 的真实频偏以频率计测晶振的 −1.4 ppm 为准**，频谱仪读载波的绝对值仅供参考。
>    如需把偏差责任分到仪器/DUT，需用信号源对零或频谱仪的频率计数器功能复测。

## 四、结论

### 4.1 载波频率（三点已测全）✅

- 三个频点偏差均在 **−5 ~ −8 ppm**，**满足 ±10 ppm 目标**；
- 绝对偏差 ≤ **20 kHz**，只占 2 MHz 信道宽度的 **1%**，**远小于 2M PHY 解调容限**；
- 主机与从机为同一块板、同一份固件，两端频偏**同向**，**相对频差接近 0**，
  对链路余量的影响可忽略；
- **2478 MHz（应用信道 78）的偏差与另两点一致**（−5.7 ppm），说明靠近 2.4G 上限时
  频率合成依然正常，无异常。

### 4.2 与晶振基准的差异（约 4~6 ppm）

频率计测晶振为 −1.4 ppm（折合 2474 MHz 上 −3.5 kHz），频谱仪读载波为 −5 ~ −8 ppm。
这部分差异**不能全部归到 DUT 上**（见 3.1 测量说明第 2~4 条）。要精确定论需换测量条件。

### 4.3 发射功率

_待测（见 3.2）。_

### 4.4 总体判定

**应用频段 2474 / 2476 / 2478 MHz 的载波频率性能正常，满足 ±10 ppm 目标**；
功率一致性待 3.2 数据补齐后最终确认。

## 五、复现步骤

```bash
# 1) 编译
cd RF_TEST && cmake -B build -G "Unix Makefiles" && cmake --build build -j"$(nproc)"

# 2) 烧对应频点的 hex 到 CH570Q 板
#    2474 MHz -> RF_TEST_2474M_ch36.hex
#    2476 MHz -> RF_TEST_2476M_ch37.hex
#    2478 MHz -> RF_TEST_2478M_ch38.hex

# 3) 上电：LED 先闪 N 次提示频点（1/2/3 = 2474/2476/2478），随后常亮 = 正在发射
# 4) 频谱仪：中心 2476 MHz、Span 20 MHz、RBW 100 kHz，用 Peak Search 读峰值频率与功率
```

> 用法细节（接线、命令、两个坑）见 [`../RF_TEST/README.md`](../RF_TEST/README.md)。
> ⚠️ 若要拆天线做传导测试，**绝不能空载发射** —— 必须接 50Ω 负载或测试电缆。
