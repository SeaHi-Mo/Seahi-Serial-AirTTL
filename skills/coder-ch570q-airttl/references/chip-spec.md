## 一、系列与选型

| 型号 | 说明 |
|---|---|
| **CH572** | 集成 2.4G 无线 + **BLE 5.0** + USB 全速的 RISC-V MCU |
| **CH570** | **低功耗 2.4G 无线 MCU，不支持蓝牙**，其它模块参考 CH572 |

**本项目主控是 CH570Q**（CH570 的一种封装）。CH570 有 **CH570E / CH570Q / CH570D** 三种封装，同系列芯片共用 `CH572DS1` 手册与同一套 SDK。

> 因此：代码里 `ID_CH570=0x70` / `ID_CH572=0x72` 两个 ID 都在（见 `CH572SFR.h`），SDK 文件名仍叫 `CH572*`。**B 项目没有使用蓝牙**——用的是 2.4G 私有协议（GFSK）。

## 二、内核与存储

| 项 | 参数 |
|---|---|
| 内核 | 青稞 32 位 **RISC-V3C**，低功耗三级流水线，特有高速中断响应机制 |
| 指令集 | **RV32IMBC** + 自扩展指令（`xw`） |
| 主频 | 多档，**最高 100 MHz** |
| Flash | **256 KB** FlashROM |
| SRAM | **12 KB**（双电源供电的睡眠保持存储区） |
| 安全 | AES-128 加解密、芯片唯一 ID |

### 地址映射（手册 §2.3）

| 地址范围 | 用途 |
|---|---|
| `0x0000_0000 - 0x0003_FFFF` | 片上 CODE 区（FlashROM，256 KB） |
| `0x2000_0000 - 0x2000_2FFF` | 片上 DATA 区（SRAM，12 KB） |
| `0x4000_0000 - 0x4000_FFFF` | 各种外设 |
| `0xE000_0000 - 0xE000_FFFF` | 系统控制空间 SCS |

### CODE 区分区（手册 §2.3.1）—— **与 `Link.ld` 直接对应**

| 地址范围 | 用途 | 大小 |
|---|---|---|
| `0x0000_0000 - 0x0003_BFFF` | **用户应用程序存储区 CodeFlash** | **240 KB** |
| `0x0003_C000 - 0x0003_DFFF` | 系统引导程序 BootLoader | 8 KB |
| `0x0003_E000 - 0x0003_FFFF` | 系统非易失配置信息 InfoFlash | 8 KB |

**本项目对应关系**：

- `Ld/Link.ld`：`FLASH 240K @0x00000000`、`RAM 12K @0x20000000` ✅ 与手册一致
- 从机绑定信息存 `BOUND_INFO_FLASH_ADDR = 1024*236 = 0x3B000`，即 **CodeFlash 最后 4 KB 扇区** → 用户可用 **236 KB**
- 现在能解释 README 里"Flash 可用区仅 236 KB"的由来

## 三、外设地址分配（手册 §2.3.3）

| 模块 | 基址 |
|---|---|
| SYS（PMU / RTC / GPIO / KEYSCAN 等） | `0x4000_0000` |
| FlashROM-Control | `0x4000_1800` |
| TMR | `0x4000_2400` |
| **UART** | `0x4000_3400` |
| SPI | `0x4000_4000` |
| I2C | `0x4000_4800` |
| PWMx（PWM1~5） | `0x4000_5000` |
| **USBFS** | `0x4000_8000` |
| **Radio : BLE** | `0x4000_C000` |

> 项目代码里直接用寄存器地址的地方，都能对到上表。例：`R8_UART_THR` / `R8_UART_LCR` 等即 UART 基址 `0x4000_3400` 起的寄存器。

### 其他外设资源（手册 §功能）

- 2.4G / BLE 射频：GFSK 调制解调，**2.4G 模式最高 8 KHz 上报率**
- USB 2.0 全速控制器及 PHY：**15 个端点**、支持 64 字节数据包、支持 DMA、支持全/低速 Host 与 Device、支持单线 USB
- 定时器：1 组 **26 位**定时器，16 MHz 下最长约 4.2 s；1 路捕捉/采样（上升/下降/双边沿）；支持编码器模式
- 按键检测：**20 路**（10 路矩阵 + 10 路独立）
- 比较器 CMP：内置 16 档参考电压，**等效 4 位 ADC**
- RTC：定时和触发两种模式
- 时钟：内置 PLL、内置低频 RC 振荡器
- 电源：内置 LDO5V（5V → 3.3V）

## 四、引脚（CH570Q）

引脚号取自手册表 1-2 的 **CH570Q** 列：

| CH570Q 引脚号 | 名称 | 类型 | 本项目用途 |
|---|---|---|---|
| 0 | GND | P | 公共接地（芯片底板） |
| 1 | VDD33 | P | 3.3V 供电（需外接 2.2 µF ∥ 0.1 µF） |
| 2 | V5 | P | 5V 输入（走内部 LDO5V）；3.3V 供电时悬空或与 VDD33 短接 |
| 3 | **PA0** | I/O/A | 从机：**UART TXD** |
| 4 | **PA1** | I/O/A | 从机：**UART RXD** |
| 5 | **PA7** | I/O/A | **LED**（`LED_PIN`） |
| 7 | **PA3** | I/O/A | 从机：**BOOT_PIN / DTR_PIN**（同一只脚，默认跟随 PC 的 DTR）；主机：调试串口 TXD |
| 8 | XO | 0/A | 外接 **32 MHz 晶体**（HSE 反相输出） |
| 9 | XI | A | 外接 **32 MHz 晶体**（HSE 输入） |
| 10 | ANT | A | RF 射频输入输出，建议直连天线 |
| 7 | VIO33 | P | I/O 电源，**必须与 VDD33 短接** |

> 表中 `7` 同时出现在 PA3 与 VIO33 行——这是手册表格的跨列合并所致，**以手册原表为准**；实际硬件按原理图核对接线。
> 引脚类型：`P`=电源、`I`=TTL/CMOS 斯密特输入、`O`=CMOS 三态输出、`A`=模拟、`5VT`=支持 5V 耐压输入。
> 复用功能按**优先级从高到低**排列，**GPIO 优先级最低**。

### PA2 的复用（从机的一键下载用）

从机把 PA2 用作 `RESET_PIN`。手册中 PA2 的复用包含 `TMR_1` / `RXD` / `SCS_` / `KEYSCAN0` / `CAP_IN1_1` / `CAP_IN2` 等；本项目将其作为**普通 GPIO 输出**驱动目标板 RESET，不占用复用功能。

## 五、⚠️ 三条与项目直接相关的引脚约束

### 1. PA0 / PA1 默认是**仿真调试接口**（最重要）

手册 §1.2 注 3 原文：

> 系统上电或复位后**默认调试接口引脚功能开启**，可根据需要配置寄存器关闭调试接口。仿真调试接口启用后，**PA0 和 PA1 仅用作 SWDIO 和 SWCLK**，不再用于 GPIO 或外设复用功能引脚。关闭仿真调试接口后，PA0 和 PA1 才可用于 GPIO 和外设复用功能引脚。

**这就解释了项目里那两行"关闭两线调试"的代码**：

```c
/* RF_Uart/APP/uart.c:299  从机 UART_Init() */
R16_PIN_ALTERNATE &= ~RB_PIN_DEBUG_EN;   /* 不关，PA0/PA1 就当不了串口 */
```

> 也解释了**烧录为什么要断电重上电**：固件一跑就关掉了调试接口（PA0/PA1 变串口），WCH-Link 自然连不上。详见 [flashing.md](./flashing.md) 第二节。

### 2. 外部复位引脚可选 **PA7 或 PA8**

InfoFlash 用户级配置位（手册表 2-3）：`CFG_RST_PIN_EN` —— **1 = PA7，0 = PA8（默认 0）**。

**本项目用 PA7 做 LED**，所以**必须保持该配置为默认的 0（复位脚是 PA8）**，否则 PA7 会变成复位输入，LED 就废了。同表还有 `CFG_RESET_EN`（位 3，RST 外部手工复位输入使能，默认 0）。

### 3. 引脚选型差异

CH570E / CH570Q / CH570D 的引脚排布不同（手册表 1-2 三列）。**改板或换封装时，务必按对应列核对引脚号**，不要照搬另一封装。

### 工作电流（静态）

| 条件 | RAM 运行 | Flash 运行 |
|---|---|---|
| F<sub>sys</sub> = 8 MHz | 3.0 mA | 3.3 mA |

## 七、2.4G 射频

| 项 | 参数 |
|---|---|
| 射频 | 集成 2.4 GHz RF 收发器 + 基带及链路控制 |
| 调制 | GFSK 数字调制与解调 |
| 接收灵敏度 | **−95 dBm** |
| 发送功率 | **可编程，最高 +7.5 dBm** |
| 速率 | 支持 2 Mbps / 1 Mbps（BLE 5.0 规范） |

## 八、时钟

- 内置 PLL、内置低频 RC 振荡器
- 外部 **32 MHz 晶体**接在 `XO` / `XI`；负载电容 = 外部 **4.7 pF × 2** + 片内档位 **`HSECFG_Capacitance(HSECap_6p)`**（最小档）
  - 本项目实测 **31.999954 MHz（−1.4 ppm）**；牵引率 ≈ 10.5 ppm/pF（片内每档 2 pF ≈ 21 ppm）
  - **两个固件必须同值**（`RF_Uart` / `RF_UartDongle` 各一份），否则两侧频差会吃掉链路余量
  - 标定与重标方法见 [wch-stdperiph-api.md](./wch-stdperiph-api.md) §1.2 与 README「三、晶振与负载电容」
- 主频可切：从机默认 24 MHz，检测到波特率 **400 kbps ~ 1 Mbps** 时切 **100 MHz**；主机固定 100 MHz
- ⚠️ UART 只有**整数**分频 `DL = round(Fsys/8/baud)`（`R16_UART_DL`；`R8_UART_DIV` 预分频官方 SDK 未用），
  实际波特率是一组离散格点，高波特率下偏差明显：请求 2 Mbps 在 24 MHz 只能得 1.5 Mbps（−25%）、100 MHz 得 2.083 Mbps（+4.2%）→
  本项目从机固件因此把波特率**上限夹在 1.5 Mbps**
